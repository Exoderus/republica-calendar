# Republica | 1963 — Calendar evenimente

Interfață web pentru calendarul evenimentelor. Nu conține date: citește și scrie în Sheet-ul „Republica | 1963 — Calendar evenimente” prin serviciul din `server/` (Google Apps Script), după login cu contul Google. Accesul îl dă foaia „Echipa” din Sheet (email + „Activ”).

- `index.html` — aplicația (telefon și PC, se poate instala pe ecranul telefonului)
- `server/Code.gs`, `server/appsscript.json` — serviciul, legat de Sheet
